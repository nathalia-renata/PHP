# 🐘 Desenvolvimento Back-end com PHP

## Descrição
Projetos e exercícios práticos desenvolvidos em PHP durante o curso Técnico em Desenvolvimento de Sistemas, focados no aprendizado da linguagem e na criação de soluções que simulam cenários reais do mercado de trabalho.

**Principais funcionalidades e conceitos aplicados:**
* **Autenticação e Segurança:** Implementação de sistemas de login e validação de credenciais.
* **Gestão e Pesquisa de Dados:** Cadastro, consulta e filtragem de produtos por nome e categoria.
* **Lógica de Negócio:** Algoritmos para cálculos operacionais e processamento de dados (como cálculo de médias e manipulação de entradas).
